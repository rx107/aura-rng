# Red johnを自分で変えてみる

Red johnは、淡い壁の部屋、低いベッド、壁に描いた赤い笑顔を組み合わせたExtraオーラです。アバターは参考写真の座り方を再現します。片膝を立てて腕を乗せ、反対の手でベッドを支える姿勢です。人物の顔・髪型・服装はコピーせず、選択したブロックアバターまたはVRMに同じポーズを付けます。

Extraステージで入手できる初期の基礎確率は **1 in 6,000,000** です。これは今回の試作のために選んだ値なので、自分で変更できます。Normalのオーラは、これまでどおり全惑星で入手できます。NanallyのAdministrator分類も変わりません。

## まず画面で確認する

1. ゲームを開き、F1でデバッグ画面を表示します。
2. オーラ一覧からRed johnをプレビューします。未所持でも表示でき、AutoRollは停止します。
3. CutSceneのRed john再生ボタンを押すと、入手演出だけを確認できます。
4. ブロックとVRMを切り替えて、座り方とベッドの高さの関係を確認します。

プレビューでは所持数・ロール回数・Roll Historyを増やしません。実際にロールで入手したときは、ほかのExtraオーラと同じく所持品へ追加します。表示する装備を決める操作はCollectionが担当します。

## 数字を変える手順

1. `src/tuning/redjohn.hpp`を開き、変えたい数字を1つだけ編集します。
2. Ctrl+Sで保存します。末尾の`f`・`;`や波括弧は残してください。
3. 起動しているゲームを閉じ、ソースの一番上にある`Develop.cmd`を実行します。
4. F1から同じオーラを表示し、編集前と比べます。

保存しただけでは実行中のゲームへ反映されません。C++の数値変更には再ビルドと再起動が必要です。戻したくなったら元の数字へ戻して同じ手順を行います。`Develop.cmd`は開発専用の`local-save`を使うので、通常プレイの所持品と分けて試せます。

長さはゲーム内の単位です。ブロックアバターの身長は約3なので、`1.f`は身長の約3分の1と考えると調整しやすくなります。色は赤・緑・青の順で、基本は各成分を0〜1にします。壁を暗くするなら3つの値を少し下げ、赤い顔を暗くするなら赤の成分を下げます。

| 変えたいもの | 設定と標準値 | 変更例と画面で起こること |
| --- | --- | --- |
| 部屋の横幅 | `RoomWidth=6.5f` | `7.5f`で壁と床を横へ広げる |
| 部屋の高さ | `RoomHeight=4.8f` | `5.5f`で壁が高くなる |
| 壁の色 | `WallColor={.73f,.72f,.64f}` | 3成分を少し上げると明るい壁になる |
| 部屋の明るさ補助 | `RoomSelfLight=.45f` | `.65f`でステージの暗さに影響されにくくなる |
| ベッドの上面 | `BedTop=.60f` | `.70f`でベッドが高くなる。座る腰の高さも合わせる |
| ベッドの横幅 | `BedWidth=4.56f` | `5.f`でマットレスが横へ広がる。部屋より小さく保つ |
| 顔の大きさ | `FaceRadius=1.06f` | `1.25f`で壁の顔だけが大きくなる |
| 顔の横位置・高さ | `FaceCenterX=-.72f`、`FaceCenterY=3.36f` | Xを増やすと右へ、Yを増やすと上へ移動 |
| ペンキの線幅 | `PaintWidth=.063f` | `.09f`で線が太くなり、離れても顔を見つけやすくなる |
| ペンキの垂れ | `PaintDripScale=1.f` | `0.f`で垂れを消す。`2.f`で垂れる長さが2倍になる |
| 顔の赤 | `PaintColor={.66f,.075f,.095f}` | 1個目を下げると暗い赤、2・3個目を上げると淡い赤へ寄る |
| 埃の数 | `DustCount=12` | `6`で半分、`0`で埃を消す |
| 埃の明るさ | `DustBrightness=.075f` | `.04f`でほのかな光をさらに弱める |

`CutawayWalls=true`は、カメラを外へ回したときに手前の壁を省いて中を見せる設定です。部屋の外から見てもアバターやベッドが隠れにくいようにしています。`false`にすると壁で中が見えなくなる角度があるため、最初は`true`のまま試してください。

## 座り方を少し変える

`src/tuning/avatar.hpp`の`namespace redJohn`を開きます。ここはブロックとVRMの両方に使うポーズです。角度はラジアンで、約`1.57f`が90度です。腕や脚の配列`{左の値, 右の値}`は、1個目が立てた膝とその上の腕、2個目が横へ折り畳んだ脚とベッドを支える腕を担当します。

| 変えたいもの | 設定と標準値 | 変更例と画面で起こること |
| --- | --- | --- |
| 腰の高さ | `Lift=-.26f` | `-.20f`で全身を少し持ち上げる。ベッドとの間に隙間が出ないか確認する |
| VRMの座る基準 | `HipHeight=1.10f` | モデルごとの脚の長さの違いを吸収する基準。ここへ`Lift`を加えた高さが腰の目標位置になる |
| 体の横傾き | `BodyRoll=.025f` | `0.f`で横への傾きをなくす |
| 呼吸の大きさ | `BreathingAmplitude=.006f` | `0.f`で胸の小さな動きを止める |
| 呼吸の速さ | `BreathingFrequency=1.35f` | `.675f`で呼吸を半分の速さにする |
| 支える手の横位置 | `ArmOut={-.12f,.28f}` | 2個目を`.38f`へ増やすと、支える手を体から外へ広げる |
| 立てた膝の高さ | `LegPitch={2.40f,1.40f}` | 1個目を少し増やすと、立てた膝が高くなる |
| 横へ折る脚の向き | `LegYaw={.08f,-.90f}` | 2個目を少し変えると、折り畳んだ脚が左右へ向きを変える |
| 膝の曲げ方 | `Knee={-2.32f,-2.30f}` | 0へ近づけると膝が伸びる。少しずつ変えて床との重なりを確認する |

腕と膝が接しているポーズなので、脚を大きく変えたら`ArmPitch`・`ArmYaw`・`ElbowPitch`も少しずつ合わせます。`ArmYaw`は肩から先を左右へ向け、`ElbowPitch`は肘だけを曲げます。体の向きは部屋と一緒に回るため、カメラを右ドラッグして横からも確認すると調整しやすくなります。

## CutSceneの出る時刻を変える

参考動画の流れを約10.9秒の演出にしています。黒い導入から青・白・黄色の帯が現れ、目の接写、角のあるアバターの横顔、大きなRED JOHNの文字へ進みます。最後に赤い顔を残し、部屋のオーラへフェードしてつながります。動画をそのまま再生する処理ではなく、GPUの帯とDirect2Dのシルエット・文字を組み合わせています。

`src/tuning/redjohn.hpp`の先頭で各場面の時刻を変更できます。時刻はすべて「再生開始から何秒後か」です。大きくすると遅く、小さくすると早く始まります。F1の再生ボタンで何度でも確認できます。

| 場面・見た目 | 設定と標準値 | 変更例と画面で起こること |
| --- | --- | --- |
| 演出全体の長さ | `CutsceneDuration=10.9f` | `11.4f`で終了まで0.5秒長くする。最後のフェード位置も追従する |
| 色の帯の出現 | `PanelsStart=2.05f` | `2.15f`で帯が0.1秒遅く出る |
| 目の接写 | `EyeStart=2.85f` | `2.95f`で接写を0.1秒遅くする |
| 横顔への切り替え | `PortraitStart=3.80f` | `3.90f`で目の場面を長くし、横顔の開始を0.1秒遅くする |
| タイトルの出現 | `TitleStart=5.45f` | `5.55f`でRED JOHNの文字を0.1秒遅く出す |
| タイトルが収まる時刻 | `TitleSettle=6.05f` | `6.15f`で文字の移動を0.1秒長くする。TitleStartと一緒に+0.1なら動きの長さを保って全体を遅らせる |
| 帯が去る時刻 | `EndStart=8.75f` | `9.f`でタイトルを少し長く見せる |
| 上下の黒帯 | `Letterbox=.18f` | `.12f`で上下の黒帯を細くする。`.18f`は上・下それぞれ画面高の18% |
| 色の帯の速さ | `PanelSpeed=1.f` | `.8f`で帯の進入と模様の進み方をゆっくりにする。目・横顔・文字の開始時刻と帯の退出時刻は変えない |
| フィルムの粒 | `FilmGrain=.025f` | `0.f`で細かなざらつきを消す |

場面の時刻は`PanelsStart < EyeStart < PortraitStart < TitleStart < TitleSettle < EndStart < CutsceneDuration`の順に保ちます。たとえばタイトルだけを遅らせたいときは、まず`TitleStart`と`TitleSettle`の両方へ同じ秒数を足して比べてください。

配布版の短い導入音は、`tools/generate_redjohn_audio.py`で合成したオリジナルです。映像の切り替えへ合わせるアクセントは、同ファイルの`PANEL_ACCENTS=(2.05, 2.85, 3.80, 5.45, 6.05, 8.75)`で指定しています。上の時刻を変えたらこちらも合わせ、`python tools/generate_redjohn_audio.py`でWAVを作り直してからDevelop.cmdを実行します。`SNAP_VOLUME`を下げると切り替え音が弱くなり、`END_FADE`を増やすと最後の余韻が早めに静かになります。参考動画の音声は配布しません。

## 名前と確率を変える

`data/auras.csv`の次の行が登録内容です。

```csv
red_john,Red john,6000000,0.86,0.05,0.08,32,3.00,0.30,0
```

- `red_john`は保存やマルチプレイで使うIDです。名前だけを変えたい場合も、このIDはそのままにしてください。
- `Red john`は英語表示の名前です。日本語名は`src/core/presentation.cpp`の`displayName()`で「レッド・ジョン」にしています。
- `6000000`が基礎確率の分母です。`3000000`へ変えるとLuck 1倍で約2倍出やすくなります。Collectionの表示と抽選は同じ値を使います。
- 最後の`0`はロールで入手できる指定です。`1`はプレビュー専用ですが、その場合は分母も`0`へ変更する必要があります。

CSVを変えた場合も、元の`data/auras.csv`を保存してDevelop.cmdを再実行してください。`build-release/data`内のコピーは次回のビルドで上書きされます。

Extraへ分類する処理は`src/core/aura.cpp`の`auraCategory()`です。`availableInBiome()`がExtraステージだけに抽選を制限します。新しいオーラの確率分はExtraのStardustの余りから割り当てるため、Commonの1/2やUncommonの1/4を変えません。内部のくじは1兆枚なので、割り切れない分母は1枚未満を切り捨てます。

## 処理を読むときの入口

| 読みたいもの | 開くファイル | 担当すること |
| --- | --- | --- |
| 部屋・ベッド・赤い顔の形 | `src/render/redjohn.cpp` | アバターの位置と向きに合わせ、部屋や家具を描く |
| 見た目の調整値 | `src/tuning/redjohn.hpp` | 部屋・家具・顔・CutSceneの調整に使う数値 |
| 座りポーズ | `src/tuning/avatar.hpp`、`src/core/animation.cpp` | 首・腕・膝などの角度を決める。移動中も固定ポーズを優先する |
| CutSceneの映像 | `src/render/redjohn_cutscene.cpp` | 時刻に合わせた帯・シルエット・文字・赤い顔の演出 |
| CutSceneの音 | `tools/generate_redjohn_audio.py` | 短い鍵盤・ベース・乾いた切り替え音を数式から合成する |
| 入手とプレビューの違い | `src/platform/main.cpp` | 入手時の登録、表示だけの確認、演出の開始・終了を管理する |

参考のMP4・写真をゲームへ貼り付けたり配布したりせず、形と動きをコードで作っています。VRMはこれまでどおり各自のPCから読み込み、配布ZIPへ含めません。
