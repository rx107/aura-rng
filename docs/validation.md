# Star's RNG Alpha 0.1 / v0.1.15 検証記録

検証日: 2026-10-22（日本時間）。Windows x64 Release、MSVC 19.39。コア・Discord IPCの2テストが成功しました。

## EquinoxのBGMと拍

- 通常表示は提供された`Koraii_Layers_Cut.mpeg`、CutSceneは従来の`Equinox_Cutscene.m4a`です。通常曲は148.24秒・28,461,504 PCMバイトへ復号し、再生・切替時の停止を確認しました。
- 通常曲148秒全体の288主拍は180.002 BPM・最初の拍+0.044秒、CutSceneの21主拍は179.975 BPM・+0.056秒でした。既定値は両方180 BPMと各時差です。主拍のフィット残差中央値は通常1.74ms、CutScene2.75msで、音声出力装置の遅延は含みません。
- F1から通常/CutSceneのBPMと時差を別々に変更・保存・再読込。BPM30〜300、時差±2秒の境界、不正値、schema1〜8の移行を検証しました。
- 音声のサンプル時計から拍を求め、ループごとに先頭の拍へ合わせ直します。小数拍・正負の時差・整数拍で切れていない曲のループ・不正な時計をコアテストで確認しました。

## Equinoxの描画

- 玉の半径1.35→1.55、周回半径2.25→3.0。1000時刻と各40区間の過去位置で、反対の位置・白1個と黒1個・上下範囲を検証しました。
- 古い波線や点を削除し、過去の位置を結ぶ40区間のトレイルへ変更。先端ほど細く薄くなり、玉の中心へ接続します。
- 1拍ごとの白黒交換と同じ時計で、交換位置からリング・破片・短い光を描きます。32箇所の色交換境界と爆発の開始を検証しました。
- 床文字は4拍ごとに陰→陽→衡→無、16拍で1巡。20区間の境界と4文字の画像を確認しました。4.0/4.12/4.65拍の爆発前後、周回、雷雲の連続40画像を撮影しています。
- CutSceneの上下動は独立したCutScene用の拍へ同期。最後0.8秒の映像・音声フェードを維持しています。

## PharaohとBreakThrough

- Pharaohの床線.095→.28、ピラミッド線.10→.30、羽の幅2.3→3.45。片側16本の長短の羽根と宝石、太陽の半径.78・二重リング・16光線を正面・斜め・上方で確認しました。最大437枚のエフェクトは検証上限600枚以内、Dune/Mirageは従来の300枚以内です。
- BreakThroughはiv字幕中の`13.0 <= t < 14.12`秒だけ白い背景・黒い柱と光の二値表示へ切替。字幕とSkipも白黒です。12.999/13.0/14.119/14.12秒の境界を撮影し、適用中のRGBが0か255だけであることを確認しました。
- カメラと柱の位置を変えず色を変換しています。14.15秒からの黒画面・get out of my head、原版へ復元したi/iiと後半を維持。29.999秒まで映像と音量を保ち、30秒で通常オーラへ即切替します。
