# Star's RNG Alpha 0.1 / v0.1.14 検証記録

検証日: 2026-10-22（日本時間）。Windows x64 Release、MSVC 19.39。コア・Discord IPCの2テストが成功しました。

## BreakThroughの復元と切り替え

- 初実装は公開タグ `v0.1.6-alpha.1` の `src/render/breakthrough.cpp` で確認しました。i・ii・15.05秒以降の構図、光の大きさと強さ、絞り切り替え、最後の閃光を復元しています。
- 初実装の9時刻のカメラ座標・注視点・傾きへ照合しました。iiiはv0.1.13の直進加速、ivは同版の広角・白閃光・前進速度を維持しています。ivの終了を14.15秒に短縮しても、カメラの速度は上げません。
- iの1.5秒、iiの5.4秒、後半の18秒を初実装時の撮影画像と比較。iiiの9.6秒とivの13.4秒はv0.1.13最終版の画像と比較し、復帰・維持する画面を確認しました。
- 14.15〜15.05秒は完全な黒画面です。14.5秒の画像で、文字部分以外の背景が黒であることと、get out of my headの文字が存在することを確認しました。
- `it wasn't gone` と `with only 5 fragments left` は共通の傾き-2度、毎秒6px・最大4秒の横移動を使います。同じ経過時間での移動量、開始・停止時刻を検証し、両方が出る20.4秒の画像も確認しました。
- 映像を240時刻で調べ、黒画面を含む区間境界と有限のカメラ値を検証しました。原版の冒頭0.25秒の導入、i〜iiiの開口、28〜29秒の絞り閉鎖、29.05秒の閃光は映像の一部として残しています。
- 通常オーラへの終了クロスフェードはBreakThroughだけ廃止しました。29.5秒と29.999秒にワールドの描画数が0で、映像にオーラが透けないことを確認。29.5秒の音声出力音量が設定値と一致し、30秒の次のフレームに対応オーラを描画して音声を停止することも確認しました。
- Equinoxの最後0.8秒の映像・音声フェードは継続し、下にオーラを表示する既存テストも通りました。サックスに合わせた8単語とF1からの時刻調整・保存も維持しています。
- BreakThroughのHLSLはFXC `ps_4_0 /O3 /Ges` とゲームでコンパイル成功。GPUで100枚の連続画像に加え、場面境界・黒画面・終了前後を撮影しました。

## 回帰確認

- NVIDIA GeForce RTX 3050とDirectX WARPで全21項目、6惑星、Collection4分類、ロケット、右ドラッグ、リサイズ、プレビュー・装備・履歴の分離を確認しました。
- Extraの64回の実際の抽選で4種の限定オーラ、取得時CutScene、実装備の維持を確認。Common1/2、Uncommon1/4、各惑星の確率合計・入手制限もコアテストで維持しています。
- ローカルVRM124172頂点・22描画、自作fixture32頂点・11関節で読込・歩行・固定姿勢・欠落時復帰を確認しました。提供VRMは配布しません。
- PixelationのLv2/3の弾・衝突・爆発・浮遊の共通速度、上下軌道、トレイル、BPMと時差の保存を確認。Illusionaryの後屈と上向きの頭・肘、Equinox、Nanallyの描画も確認しました。
- 開発PCでは6音源の復号・再生・切替・停止を確認。BreakThroughの音声は5760000 PCMバイトの30秒クリップです。WARPでは `--silent` を使い、無音実行を音声再生成功として扱いません。
- 進行データとSettings schema1〜7、UTF-8設定、Discord IPCの回帰テストが通りました。
