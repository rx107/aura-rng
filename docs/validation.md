# Star's RNG 検証記録

## v0.1.19 / Red johnの音楽のみ変更

提供MP4のAAC音声を再圧縮せず`Red_John_Cutscene.m4a`へ抽出。元の44.1kHz・ステレオを維持し、元MP4とM4Aを復号したPCMの一致を確認しました。長さは約10.89秒です。

実機で同梱M4Aの読み込み・再生、自然終了と中止時の停止、演出の終了／中止と表示復元を確認しました。部屋・ポーズ・映像・時刻・確率・他のオーラは変更していません。以下のv0.1.18の合成曲の記録は当時のものです。

## v0.1.18 / Red john

検証日: 2026-10-25（日本時間）。Windows x64 Release / MSVC 19.39。コア・専用サーバー・Discord IPC・実WinHTTPクライアントの4テストが成功しました。

- 全23行・取得可能22種類・Extra6種類。Red johnのExtra限定1 in 6,000,000、Normal/Desertとの分類、確率合計、既存22行のセーブからの移行を検証しました。Common1/2・Uncommon1/4は維持しています。
- 実機GPU（RTX 3050）と、配布フォルダーのEXEによるDirectX WARPで描画試験が成功しました。部屋は正面で241個の共有立方体。正面・左右・背面の壁の切り欠き、ベッド、赤い顔とポーズを画面で確認しました。
- ブロックとローカルVRMの固定座りポーズを確認。移動しても歩行の手足の振りが混ざらず、通常オーラへ戻すと既存の歩行を使います。公開用VRMフィクスチャでも検証し、私有VRMは配布しません。
- 約10.9秒の帯・目・シルエット・文字のCutScene、1000×700への変更、自然終了のオーラ表示、Esc／停止による元の表示への復元を検証。プレビューと演出は所持数・実装備・Roll Historyを変更せず、AutoRollを止めます。Extraの実際の64ロールで6種類すべてを取得し、対応する入手演出が発火しました。
- オリジナル導入WAVを実機で読み込み・再生し、終了／中止で停止することを確認。生成スクリプトの再実行で同一バイト、PCM最大振幅0.82、音割れなし、先頭・末尾の無音を確認しました。参考MP4・写真を埋め込む処理はありません。
- 既存オーラ・惑星移動・右ドラッグ・オンライン接続後の入力／プレビュー・セーブの回帰試験も成功しています。通信はprotocol=1のままで、VPSへの変更は不要です。

以下は変更前の版の記録です。件数や数値は当時のものとして残しています。

## v0.1.16 / Frutiger Aeroとマルチプレイ

検証日: 2026-10-23（日本時間）。Windows x64 Release / MSVC 19.39。コア・専用サーバー・Discord IPC・実WinHTTP接続の4テストが成功しました。

## Frutiger Aero

- カタログ22件、抽選対象21件、Extra5件へ拡張。Frutiger AeroはExtra限定1/5,000,000で、他惑星では出ません。Common1/2・Uncommon1/4を維持し、余りをStardustへ配分する確率合計を検証しました。
- 草原と小川、流れる雲と青空、透明な反射の泡、羽ばたく青蝶を専用HLSLで描きます。通常のアルファ合成、遠い面からの順序、床の表裏を確認しました。参考画像を読み込む処理はありません。
- 最大339枚。GPUとWARPでプレビュー・時間変化・床の上面・他のオーラへの切替を確認。プレビューによる所持数・履歴・実装備の変更はありません。Extraの高Luckの64回の実抽選で5種すべてを取得しました。

## マルチプレイ

- Python専用サーバーのHTTP統合6試験と、実WinHTTPクライアント2個の接続試験に成功しました。UTF-8名前、別々の10桁ID、位置・向き・歩行・惑星・服色・実装備IDとLevel、写真、改名、退出を確認しました。
- Windowsの暗号乱数でIDと256bit秘密鍵を作り、IDの永続化とDPAPI暗号化を検証。二重接続の拒否、他人の予約IDとの衝突時の再生成・保存、サーバー再起動後の照合を確認しました。実際のID・秘密鍵は検証記録へ転記しません。
- プロフィール写真をWICで中央160×160へ変換し、PNGの寸法・CRC・展開サイズ・メタデータ除去・128KiB上限を検証。2人で異なる写真を共有でき、ゲームのプロフィール欄にもGPUで表示しました。
- 接続・更新・切断は専用スレッドです。submitとdisconnectが250ms以内で戻ること、未起動サーバー・通信失敗・不正JSON/数値/画像・32人上限・12秒の失効・接続頻度制限を確認しました。
- 外部HTTP、URL内資格情報、証明書検証を省略する接続は使いません。Windows統合認証も送信しません。公開サーバーはHTTPS、PC内試験はlocalhostのHTTPです。
- ゲーム描画では同じ惑星の架空2人の位置・詳細オーラ・名前とIDを確認し、別惑星の人を除外。入力補間とウィンドウ終了時の復帰を確認しました。写真は参加者欄に表示します。近い4人が詳細オーラ、残りは軽い星と色です。
- ロール・所持品・Luckは各PCに保存し、このプロトコルでは送信しません。VPSへの実配置、インターネット越しの遅延やHTTPS証明書発行は未検証です。同梱手順とsystemd/Caddy設定は配置用の成果物です。

## Equinoxと回帰確認

- 玉半径1.80、周回半径3.60、高さ2.70。速度は平均テンポを保ち78〜122%で加減速します。10,001点で単調進行・正の速度・反対配置・トレイル接続を確認し、強弱0の別設定でもコアテストが通りました。
- 爆発の範囲1.65・明るさ.82・破片18、床面と輪と粒子の共通回転1.10 rad/sを確認。拍・床文字・通常BGM/CutScene別の時差設定は維持しています。
- NVIDIA GeForce RTX 3050とDirectX WARPで全22項目・6惑星・Collection4分類・ロケット・右ドラッグ・リサイズ・オーラLevel・CutScene・装備とプレビューと履歴の分離を検証しました。WARPは無音実行で、音声成功とは扱いません。
- 開発PCで従来の7音源の再生・切替・停止を確認。ローカル私有VRM124172頂点と自作fixture32頂点で立ち姿・歩行・固定姿勢・欠落時復帰を確認しました。マルチ相手はブロック表示でVRMを通信しません。
- Settings schema1〜9の移行、Unicodeパス、未確定UserName、写真の保存先、接続先、各種不正値を検証。実Discordプロフィールの見え方はこの記録の対象外です。
