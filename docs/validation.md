# Star's RNG 検証記録

## v0.1.21 / 全面ゲーム画面と左右メニュー

検証日: 2026-10-29（日本時間）。Windows x64 Release / MSVC 19.39。コア・専用サーバー・Discord IPC・実WinHTTPクライアントの4テストが成功しました。

ステージ・アバター・オーラとマルチプレイ相手の名前をウィンドウ内側全体へ描画し、旧Collection・履歴・上下の常設パネルを撤去。1440×900と1000×700への変更、旧パネル位置での視点操作、英語・日本語の左右メニューと接続先画面を確認しました。OSのウィンドウモードは変更していません。

- 星の0.65秒・1回転後の表示、連打による再スタートの防止、閉じた後の再表示防止、左右メニューの排他をコアと実機で検証。左4項目を押しても画面・所持品・履歴・実装備は変化しません。
- 右メニューから実際のF1画面と接続先画面が開き、保存だけでは接続しないこと、Esc・F1・×による入力復帰、開いた時のAutoRoll停止、移動キーと右ドラッグの解除を確認。ゲーム終了は確認なしで終了フラグが立つところまで検証しました。
- ImGuiウィンドウが覆っている範囲では後ろの星・三本線へクリックが抜けず、その外側の三本線ではメニューを開けます。入力途中の接続先は通信更新で書き戻しません。
- 接続先の正規化は実装の関数を使った22ケースで確認。外部のURL/IPはHTTPS、ローカルはHTTP:8765へ補完し、パス・資格情報・クエリ・不正ポートなどは拒否します。ライブVPSは変更せず、実通信は既存のローカルHTTPクライアント／サーバー試験で確認しています。

実機GPU（RTX 3050）と配布フォルダーのEXEによるDirectX WARPで、描画・入力・全オーラ・惑星移動・CutScene・マルチプレイ表示とプレビューの回帰試験が成功。公開用32頂点VRMフィクスチャと隔離セーブを使用しました。無音試験のため今回の結果を音源再生の確認とは扱いません。音源・確率・通信プロトコルは変更していません。

## v0.1.20 / 画像ロゴと周回ロケット

検証日: 2026-10-28（日本時間）。星・文字・ロケットの透過PNG3枚は提供された元ファイルとSHA256が一致し、画像自体の加工はありません。実行時に透明な余白を除き、縦横比を保った表示用Bitmapを作ります。

実機GPUと配布フォルダーのEXEによるWARP描画試験が成功しました。起動時と1000×700／1440×900へのリサイズ後に画像3枚が読み込まれることを検証。5秒の周回を8地点で撮影し、白い輪に沿う位置、接線方向の機首、星の手前と奥での描画順を目視確認しました。ロゴとALPHA表示・操作ボタンの重なりや、ヘッダーからのはみ出しはありません。

Bitmapは起動・リサイズ時に準備し、通常フレームでPNGを再読み込みしません。元画像の色・形と透過を維持し、読み込み失敗時は従来のロゴへ戻す構成です。オーラ・音源・確率・セーブ・通信方式は変更していません。既存のロール、プレビュー、右ドラッグ、マルチプレイ入力、ステージ、CutSceneの回帰試験も成功しています。

## v0.1.19 / Red johnの音楽のみ変更

提供MP4のAAC音声を再圧縮せず`Red_John_Cutscene.m4a`へ抽出。元の44.1kHz・ステレオを維持し、元MP4とM4Aを復号したPCMの一致を確認しました。長さは約10.89秒です。

実機で同梱M4Aの読み込み・再生、自然終了と中止時の停止、演出の終了／中止と表示復元を確認しました。部屋・ポーズ・映像・時刻・確率・他のオーラは変更していません。以下のv0.1.18の合成曲の記録は当時のものです。

## マルチプレイ

- Python専用サーバーのHTTP統合6試験と、実WinHTTPクライアント2個の接続試験に成功しました。UTF-8名前、別々の10桁ID、位置・向き・歩行・惑星・服色・実装備IDとLevel、写真、改名、退出を確認しました。
- Windowsの暗号乱数でIDと256bit秘密鍵を作り、IDの永続化とDPAPI暗号化を検証。二重接続の拒否、他人の予約IDとの衝突時の再生成・保存、サーバー再起動後の照合を確認しました。実際のID・秘密鍵は検証記録へ転記しません。
- プロフィール写真をWICで中央160×160へ変換し、PNGの寸法・CRC・展開サイズ・メタデータ除去・128KiB上限を検証。2人で異なる写真を共有でき、ゲームのプロフィール欄にもGPUで表示しました。
- 接続・更新・切断は専用スレッドです。submitとdisconnectが250ms以内で戻ること、未起動サーバー・通信失敗・不正JSON/数値/画像・32人上限・12秒の失効・接続頻度制限を確認しました。
- 外部HTTP、URL内資格情報、証明書検証を省略する接続は使いません。Windows統合認証も送信しません。公開サーバーはHTTPS、PC内試験はlocalhostのHTTPです。
- ゲーム描画では同じ惑星の架空2人の位置・詳細オーラ・名前とIDを確認し、別惑星の人を除外。入力補間とウィンドウ終了時の復帰を確認しました。写真は参加者欄に表示します。近い4人が詳細オーラ、残りは軽い星と色です。
- ロール・所持品・Luckは各PCに保存し、このプロトコルでは送信しません。VPSへの実配置、インターネット越しの遅延やHTTPS証明書発行は未検証です。同梱手順とsystemd/Caddy設定は配置用の成果物です。
