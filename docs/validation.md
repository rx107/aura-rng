# Star's RNG Alpha 0.1 / v0.1.13 検証記録

検証日: 2026-10-22（日本時間）。Windows x64 Release、MSVC 19.39。コアとDiscord IPCの2テストが成功しました。

## 今回変更した部分

- BreakThroughのカメラを純粋な座標計算として検証。iの見上げと周回、iiの見下ろし・後退・ロール、iiiの向きを変えない加速接近、ivの白閃光・広角・微小な上下・終了までの前進を確認。全区間240点で有限の座標を確認しました。
- 各区間の静止画を撮影し、iiiでコアの光も大きくなること、ivで手前の大きな柱と奥の柱が同時に見えることを確認。通常オーラ名の高さは3.85です。
- Illusionaryは胸・首・全身のPitchの合計が約π/2、片肘だけ90度、両腕は非対称。ブロックの正面・側面とローカルVRMで確認し、移動量や歩行位相を変えても固定姿勢を維持しました。
- 自作テストVRMを32頂点・11関節へ拡張し、WARPで胸・首・肘の階層変換も確認。これはテスト時に生成する簡単な形状で、提供されたVRMとは別物です。
- Pixelationの機体を1000時刻×2機で調べ、半径2.45、上下1.65〜3.35、発射位置と機体の同じ軌道、必ず同じ点に着弾することを確認。Lv2/3の弾・爆発・アバター浮遊の時計は共通です。
- 同じ時刻・画角で鼓動0/1を描画し、キューブの拡縮を確認。120BPM・開始位相0.13秒の人工低音からテンポと位相を復元し、手動BPM、拍の時差、周期境界の連続性、無音・不正値を検証しました。
- 22050Hzのように10msで割り切れない音声でも、低音表は正確に毎秒100点です。端数の丸めによる累積ずれを防ぎます。
- 実音源の自動推定はRedline Shiftが89.6BPM、Censoredが193.6BPMでした。半拍・倍拍を選ぶ場合はF1の手動BPMと時差で調整できます。実プレイでは音声出力の再生サンプル数を使います。
- F1からBPMと時差を保存・再読込し、所持数・実装備・Roll Historyが変わらないことを確認。Settings schema7の往復とschema1〜6の移行、不正値の拒否も確認しました。

## 回帰確認

- NVIDIA GeForce RTX 3050とDirectX WARPで全オーラ、6惑星、Collection4分類、ロケット移動、右ドラッグ、ウィンドウ縮小を確認しました。
- 21項目中、取得可能20種とNanallyプレビュー1種。Normal全惑星・Desert砂漠限定・Extra4種Extra限定、Common1/2とUncommon1/4、各惑星の合計10^12チケットを維持しています。
- Extraで64回の実際のRollを行い、限定4種の取得、Equinox/BreakThroughのCutScene開始、装備不変を確認しました。
- CutSceneの自然終了は対応オーラの一時プレビュー、Esc/停止は直前の表示へ戻ります。最後0.8秒で映像と音声を同じ曲線でフェードします。
- ローカルVRMは124172頂点・22描画で確認。読み直し、歩行、固定ポーズ、ファイル不在時のブロックへの復帰を確認。提供VRMは配布対象外です。
- 開発PCで6音源の復号・ループ・切替・停止、Pixelationの衝突音、CutSceneの音声を確認。WARPの無音テストには `--silent` を使い、音声成功として扱いません。
- Equinox音声は2092800 PCMバイト、BreakThroughは5760000バイト。必要な10.9秒/30秒だけ再生。公開許可済み音源以外の参考画像・動画・VRMは配布しません。
