# Star's RNG Alpha 0.1 / v0.1.10 検証記録

検証日: 2026-10-19（日本時間）。MSVC 19.39 / Windows x64 / Release。

## 今回の変更

- 右ドラッグの水平回転を反転。上下・ズームは維持。
- 庭園・砂漠に海・森・火山を追加。ロケット発着場、惑星選択、離陸・宇宙航行・着陸を実装。
- 惑星移動の中間点で景観を切り替え、中央に着陸して保存。移動中はロール・AutoRoll・移動・カメラ入力を抑止し、在庫・装備・履歴は維持。
- BreakThroughの8単語を参考MP4の60fpsフレームから計測。clip開始は元動画の4.5秒、単語は22.466667 / 22.716667 / 22.950000 / 23.183333 / 23.416667 / 23.666667 / 23.900000 / 24.133333秒。
- CutSceneの通常再生ではXAudio2の出力サンプルを時計に使用。MP4初回デコードの待ち時間で字幕が先行しないようにした。
- F1の字幕時差±5秒・単語別時刻・初期値復帰を追加。設定schema 5に保存し、schema 1〜4を引き継ぐ。
- 景観と字幕の調整値をtuning/stages.hpp・cutscene.hppへ追加し、操作ガイドと日本語コメントを整備。

## 確認結果

- build.cmdのコア・Discord IPCテスト成功。5惑星の保存、旧設定移行、不正値拒否、移動時計の中間点/長いフレーム/二重適用防止、字幕の出現境界と時差を検証。
- NVIDIA RTX 3050とWARPの両方でD3D11 / D2D / ImGuiのスモークテスト成功。全17オーラ・ローカルVRM・音楽・各CutSceneも従来経路を確認。
- 反転した右ドラッグ/左ドラッグ、debug開閉、ボタン解放、capture loss、惑星メニューのクリック・M・Esc、到着の保存を確認。
- 惑星移動による所持数・装備・ロール回数・CSV履歴の不変、入力抑止、全5惑星の景観、ロケット3段階、通常の4096インスタンス予算内での描画を確認。
- 1440×900と1000×700の惑星メニュー画像、縮小時の閉じるボタン判定を確認。海/森/火山とロケット画面はコードで描画し、外部画像は追加していない。
- 字幕設定をCutScene再生中に適用・保存・初期値復帰できることを実アプリの処理経路で検証。実音声時計の別プローブでは初回デコード0.352秒後でも時計0秒、再生後の単調増加、再ロード時の0秒復帰を確認。
- 非ループ音声の終了時にXAudio2のサンプル数が0へ戻る挙動も実機で確認し、バッファが空になった場合は終了秒数を返してCutSceneが自然終了できるようにした。0.5秒の音声を終了後まで観測して、時計が0へ戻らないことを確認。

音声の参照: [Microsoft / XAUDIO2_VOICE_STATE](https://learn.microsoft.com/ja-jp/windows/win32/api/xaudio2/ns-xaudio2-xaudio2_voice_state)。字幕初期値は楽器の自動検出ではなく、提供動画の各単語の出現フレームから計測しています。参考MP4・画像・VRMは配布しません。

## 自動テスト

- コアテスト成功。20万回のシード再現、Common 1/2・Uncommon 1/4・全13抽選オーラの異なる確率・合計10^12チケットを検証。
- カタログ17項目中、Pixelation・Equinox・BreakThrough・Nanallyの4種類はプレビュー専用。Luck 1〜100万倍でも0チケットで、既存13種類の確率は追加前と同一。

## Discord IPC

Windowsの独立fake named pipeサーバーで、HANDSHAKE v1 → READY → SET_ACTIVITYとnonce応答、名前/回数、JSON/UTF-8、5秒の更新集約、PING/PONG、無効化/終了時の消去、切断・再接続、ERROR/過大パケット、非ブロック更新と終了を検証し成功しました。ゲームのsmokeでは実Discordへの投稿を無効にしています。

前回（v0.1.6）、実Discordデスクトップのプロセスとpipe0の実在を確認しましたが、制限された検証環境からの接続はWindows ERROR_ACCESS_DENIED (5)となりました。**実Discordの更新応答・プロフィール上の表示成功は未確認です。** 既存Discordのアクセス権は変更していません。通常の起動方法と設定は[Discord連携](discord.md)を参照してください。

## 再現

```bat
build.cmd
build-release\StarRng.exe --smoke-test --seed=42 --save-dir=C:\Temp\star-test-save --capture=C:\Temp\star-preview.png --report=C:\Temp\star-report.txt
build-release\StarRng.exe --smoke-test --warp --seed=42 --save-dir=C:\Temp\star-warp-save --report=C:\Temp\star-warp-report.txt
```

テスト用の書き込み可能な保存先を指定してください。通常のセーブには触れません。`--vrm=` / `--bgm=` / `--pixelation-bgm=` / `--pixelation-final-bgm=`でローカル資産の検証を追加できます。参考MP4音声はDownloadsの各原ファイルを使用し、動画・GIF・VRMは再配布しません。許可済みの新2曲は配布ZIPのみに含めます。

GitHub ActionsはWindowsビルド・core/Discord IPCテスト・WARP smokeと、Ubuntu coreテストを実行します。入力検証はWin32メッセージ経路によるもので、全OS入力デバイスの自動操作を保証するものではありません。VRM 1.0経路は実装し、今回の実モデルはVRM 0.x。MToon / Spring Bone / 表情は未実装です。
