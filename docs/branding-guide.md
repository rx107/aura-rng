# 左上の星・タイトル・ロケットを変える

v0.1.20から、左上の星とStar’s RNGの文字は、提供された透過PNGで表示します。白いロケットも提供画像を使い、星の輪に沿って回ります。機首は進む方向を向き、星の奥を回る間は星に隠れ、手前へ来ると星の前に表示されます。

形や色を描き直す処理はありません。元画像にある大きな透明の余白だけを、読み込み時に表示領域から外します。画像ファイルそのものは変更しません。

## まず1つの数字を変える

1. ソースZIPを展開し、`src/tuning/branding.hpp`を開きます。
2. `OrbitSeconds=5.f`を`8.f`へ変えて保存します。
3. 起動中のゲームを閉じ、プロジェクト直下の`Develop.cmd`を実行します。
4. 左上のロケットを見ます。1周が5秒から8秒になり、ゆっくり回っていれば成功です。

元に戻すときは`5.f`へ戻し、同じ手順を行います。F1で変更するプレイヤー設定とは別なので、C++の数値を変えた場合は保存だけでなく再ビルド・再起動が必要です。

## 位置・大きさ・速さ

値は`aura::tuning::branding`にまとめています。位置と大きさは、通常の1440×900画面を基準にした値です。ウィンドウの大きさを変えると、ほかのUIと一緒に拡大・縮小します。

| 変えたいもの | 設定と標準値 | 変更例と画面で起こること |
| --- | --- | --- |
| 星を左右へ動かす | `IconLeft=12.f` | `18.f`で星と周回するロケットを6だけ右へ移動 |
| 星を上下へ動かす | `IconTop=12.f` | `16.f`で4だけ下へ移動 |
| 星を大きくする | `IconWidth=64.f` | `72.f`で横幅を8だけ広げる。縦横比を保ち、輪と周回位置も一緒に広がる |
| 文字を左右へ動かす | `TitleLeft=84.f` | `90.f`で文字を6だけ右へ移動 |
| 文字を上下へ動かす | `TitleTop=17.f` | `21.f`で4だけ下へ移動 |
| 文字を大きくする | `TitleWidth=190.f` | `210.f`で横幅を20だけ広げる。文字画像の縦横比は保つ |
| ロケットを大きくする | `RocketWidth=13.f` | `16.f`で機体だけ大きくする。星と輪の大きさは変わらない |
| ロケットをゆっくり回す | `OrbitSeconds=5.f` | `8.f`で1周8秒。大きいほど遅く、小さいほど速い |
| 起動時のロケット位置をずらす | `OrbitPhase=.35f` | `.85f`で輪の上の出発位置を変える。単位はラジアンで、約6.283が1周 |
| 機首の向きを少し直す | `RocketAngleOffset=0.f` | `10.f`で、進む方向から10度だけ追加で回す。元画像の機首が右を向いているため、標準は0 |

星や文字を大きくすると、隣の文字やALPHA表示へ近づきます。最初は数ピクセルずつ変え、全体の間隔も確認してください。周回位置は星の表示位置から計算するため、`IconLeft`や`IconTop`を変えてもロケットだけが置き去りになることはありません。

## 画像を差し替える

| ファイル | 画面で使う場所 |
| --- | --- |
| `data/ui/brand-star.png` | 金色の星と白い輪 |
| `data/ui/brand-title.png` | Star’s RNGの文字 |
| `data/ui/brand-rocket.png` | 周回するロケット |

PNGを編集する場合は、背景を透明のまま保存します。黒い背景を塗ると、その黒も画面に表示されます。ロケットの機首は元画像と同じ右向きにすると、進行方向への回転をそのまま使えます。

ソースで変更する場合は`data/ui`の画像を保存し、`Develop.cmd`を実行してください。画像も`build-release/data/ui`へコピーされます。コピー先だけを直接編集すると、次のビルドで上書きされます。完成したWindows版で画像だけを試す場合は、EXEと同じ階層の`data/ui`へ同名PNGを置き、ゲームを再起動します。

大きな透明の余白が付いたPNGでも、自動的に中身の範囲へ合わせます。縦横比をつぶして引き伸ばすことはありません。提供画像はそのままソースと配布版に同梱し、別の画像を自動生成する処理はありません。

前の線で描いた星と通常の文字へ戻った場合は、`data/ui`に3枚ともあるか、PNGとして開けるかを確認してください。画像を読めない場合でもゲームを続けられるよう、従来の表示へ戻す処理があります。画像の修正後は再起動すると読み直します。

## 別の輪の形に合わせる場合

次の値は、元の星画像の1280×1280座標で輪の位置を表しています。標準の星画像を使う場合は、通常この部分を変える必要はありません。

| 設定 | 標準値 | 意味 |
| --- | --- | --- |
| `RingCenterX` / `RingCenterY` | `642.911f` / `646.999f` | 楕円の中心。画像の左上が0,0、右がX増加、下がY増加 |
| `RingMajorRadius` | `599.042f` | 楕円の長い方向の半径。増やすと長い方向へ軌道が広がる |
| `RingMinorRadius` | `149.134f` | 楕円の短い方向の半径。増やすと輪がふくらむ |
| `RingTiltDegrees` | `-25.622682f` | 楕円の傾き（度）。画像上で右上がりになる角度 |

星画像を別の輪へ差し替えたときだけ、ロケットが輪から外れないよう、この楕円を合わせます。`IconWidth`は画面上の大きさ、`RingMajorRadius`などは画像の中の軌道なので、役割が違います。

## コードを読む入口

- `src/tuning/branding.hpp`：最初に触る数値とコメント。
- `src/render/branding.cpp`：透過画像を読み、余白を外し、輪の位置と進む向きからロケットを描く処理。
- `src/render/ui.cpp`：通常画面のヘッダーからブランド表示を呼ぶ場所。
- `src/render/renderer.cpp`：画面サイズが変わったときに、Direct2Dで使う画像も用意し直す場所。

この表示は所持品・確率・オーラの演出・音楽・マルチプレイの通信内容を変更しません。オーラに使う小さな星や、Rollの待ち時間の星は、それぞれ従来の描画を使います。
