# オーラの共通データ仕様 v2

`data/auras.csv` はUTF-8です。BOM、CRLF、引用符、日本語名に対応します。名前にカンマがあれば引用符で囲み、名前内の引用符は二重にします。

| 列 | 意味 / 制限 |
| --- | --- |
| id | 保存用の不変ID。小文字英字・数字・_・-、1〜64文字、重複不可 |
| name | 表示名。1〜128 UTF-8バイト、改行・タブ不可 |
| denominator | 基礎確率1/NのN。2〜10^12。0は残余確率、またはプレビュー専用 |
| red / green / blue | 標準色。各0〜1 |
| particles | 標準粒子数。0〜160 |
| radius | 標準リング/粒子の半径。0.5〜3 |
| speed | 標準回転係数。0〜4 |
| preview_only | 0は取得可能、1は試作用表示だけ。1なら分母0が必須 |

旧9列のヘッダーも読み、その場合は全行を通常の抽選対象とします。カタログは1〜4096行、残余確率を受け取る非プレビュー行は1件必要です。確率合計に余りがなくなる指定や、不正な値は起動時に拒否します。

## 分類と入手場所

分類は `src/core/aura.cpp` の `auraCategory()` がIDで決め、`availableInBiome()` が対象惑星を確認します。新しいテーマを作る場合はここも変更します。

| 分類 | ID | 入手場所 |
| --- | --- | --- |
| Normal | 下記以外の13種 | 全惑星 |
| Desert | dune / mirage / pharaoh | Desertのみ |
| Extra | pixelation / equinox / breakthrough / illusionary | Extraのみ |
| Administrator | nanally | ロール対象外 |

現在は21行中20種が取得可能です。Nanallyだけ `preview_only=1`。F1からすべてを表示でき、プレビューは取得や履歴へ登録しません。

## 確率の計算

1回のRollで `std::mt19937_64` と一様分布から0〜999,999,999,999のチケットを1枚引きます。現在の惑星で有効な各行に `floor(10^12/N)` 枚を割り当て、残りをStardustへ配分します。合計は10^12枚で、結果は常に1種です。惑星を変えてもCommon1/2・Uncommon1/4・Singularity1/10億など指定分母は維持します。

| 惑星 | Stardustのチケット | 割合 |
| --- | --- | --- |
| 庭園・海・森・火山 | 69,888,989,000 | 6.9888989% |
| 砂漠 | 49,684,989,000 | 4.9684989% |
| Extra | 69,887,505,667 | 6.9887505667% |

ExtraではBreakThroughの分母3,000,000が10^12を割り切らず、333,333枚となります。切り捨て誤差は絶対確率10^-12未満です。画面の1/NはCSV基準、残余確率は現在の惑星の概算を表示します。CSV履歴には設定上の分母を保存します。

Luck L倍は、よく出る順に並べたCDF FをF^Lへ変換し、隣との差を新しいチケット数にします。L回分の最良結果と同じ分布を1回で引き、小数倍率と最大100万倍に対応します。対象外の行はこの計算にも入れません。F1ワールドの確率はLuck反映後、Collectionは基礎値です。

## 保存と演出

IDを並べ替えたり表示名を変えても、同じIDなら在庫を保持します。消したIDもセーブに保持し、再追加すれば復元できます。既存IDを別オーラに使い回さないでください。Common/UncommonのIDは旧版互換のためstill/glimmerです。

Singularity / PixelationのLevelは `min(3,max(0,count-1))`。初取得0、重複で上昇します。F1のLevelは一時的な上書きです。特殊演出はIDごとのC++コードと `src/tuning` の値で描くため、CSVだけで全ての形が変わるわけではありません。

Equinox / BreakThroughは入手時にCutSceneを再生します。F1の演出のみ再生でも同じ映像が流れますが、取得・装備・履歴は追加しません。最後は対応オーラの一時プレビューへフェードし、Esc / 停止なら前の表示へ戻します。[調整手順](stage-and-cutscene-guide.md)
