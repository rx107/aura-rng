# 全面ゲーム画面とメニューを変える

ステージ・アバター・オーラを**ウィンドウの内側全体**に描き、その上へロゴ・メニュー・Rollボタンを重ねます。v0.1.22ではクレジットを実際に開けるようにしました。Windowsのタイトルバーやウィンドウモードは従来どおりです。

## どのボタンが何をする？

左上の星を押すと、星が**0.65秒で1回転**し、回り終わってから左メニューが開きます。回転中の連打はため込まず、開いているときに星を押すと閉じます。タイトル画像と、輪を回るロケットは引き続き表示します。

| 左メニューの順番 | 現在の動き |
| --- | --- |
| マルチプレイヤー / Multiplayer | 表示のみ |
| 設定 / Settings | 左側に設定のサブメニューを開く |
| クレジット / Credits | スタッフクレジットを開く。文字・画像が順々に現れ、開くときに「ポコッ」と鳴る |

クレジットは不透明度70%の灰色の四角いパネルです。v0.1.23で30%から濃くしました。「credits」は最初から固定位置に表示し、内容は左上→左下→右上の順で、左から滑りながらフェードインします。×・Esc・パネル外のクリックで閉じられ、開き直すと最初から始まります。後ろのワールドとBGMは続き、ロール・移動・AutoRollは止まります。[内容と数値の調整](credits-guide.md)

左上の星のメニューで**設定**を押すと、同じ場所に以下のサブメニューが開きます。一番上の戻る矢印で星のメニューへ戻れます。

| 設定の項目 | 実際の動き |
| --- | --- |
| デバッグメニューを表示 | Dear ImGuiのデバッグ画面を開く。未所持オーラのプレビュー、Luck、服色、惑星などを変更できる |
| マルチプレイヤーIPを設定 | 接続先の保存、ユーザー名の入力、接続・切断を行う専用画面を開く |
| ゲーム終了 | 確認画面を出さず終了する。通常の終了と同じ保存処理を行う |

星のメニューと設定のサブメニューは、不透明度68%の四角いパネルです。RollとAutoRollはゲーム画面の下中央にあります。

## オーラを選ぶ

1. 右下の**白い炎**を押すと、不透明度70%の灰色のパネルが右側に開きます。
2. 下の**Normal / Desert / Extra / Administrator**からカテゴリを選びます。上の一覧にカーソルを置き、ホイールでスクロールします。
3. 一覧の行を選ぶと、左下に名前と`1 in 〇〇`形式の確率が表示されます。限定オーラの確率は入手可能なステージを基準に表示します。
4. 所持しているオーラを装備するには、左下の**装備する**を押します。未所持やAdministratorの項目は詳細を閲覧できます。見た目を試す場合はF1のプレビューを使います。

炎をもう一度押すか、**×・Esc・パネル外のクリック**でゲームに戻れます。

## キーボードでも操作する

| 操作 | 動き |
| --- | --- |
| R / Space | Roll |
| F | AutoRollの開始・停止 |
| WASD / 矢印 | 移動 |
| 右ドラッグ | 視点回転。右へドラッグすると左回転 |
| マウスホイール | ゲーム画面ではカメラの距離を変更。オーラ一覧では上下にスクロール |
| M | 惑星選択を開く |
| F1 | デバッグ画面の表示を切り替える |
| Esc | 開いているオーラ選択・メニュー・クレジット・設定画面・惑星選択を閉じる。CutScene中は再生を止める |

メニューや文字入力画面が開いている間は、クリック・入力が後ろのゲームへ抜けないようにします。移動と視点操作へ戻るには画面を閉じてください。

## マルチプレイの接続先を保存する

1. **左上の星 → 設定 → マルチプレイヤーIPを設定**を開きます。
2. サーバーURLまたはIPアドレスを入力します。自分のPC内の試験なら`http://127.0.0.1:8765`です。先に`Start-local-server.cmd`を起動してください。
3. **接続先を保存**を押すと次回起動にも残ります。このボタンだけでは接続しません。
4. ユーザー名を入力して**接続する**を押します。接続する場合は、入力した接続先と名前も保存します。
5. **ゲームに戻る**、右上の×、またはEscで画面を閉じます。接続を終える場合は**切断する**を押します。

外部の接続先はHTTPSを使います。ホストから教わった`https://rng.example.com`のようなルートURLを入力してください。URLの末尾にゲームの画面名やクエリは付けません。IPだけの入力は外部ならHTTPS、`localhost`や`127.0.0.1`ならHTTPへ補完され、ローカルのポート省略時は8765番になります。証明書の設定はサーバー側で必要です。[サーバー配置の手順](multiplayer.md)

この画面は接続先と名前のための画面です。以前の写真データや10桁UserIDは引き継ぎますが、この画面には写真選択欄を置いていません。通信形式はprotocol 1のままで、このUI変更のためにVPSを更新する必要はありません。

## 最初にメニューを少し透かしてみる

1. [src/tuning/shell.hpp](../src/tuning/shell.hpp)をエディターで開きます。
2. `PanelOpacity`を検索し、次の`.68f`だけを`.50f`へ変えます。

```cpp
// 変更前：不透明度68%。後ろが少し見える。
inline constexpr float PanelOpacity=.68f;

// 変更後：不透明度50%。後ろのゲームがもっと見える。
inline constexpr float PanelOpacity=.50f;
```

3. Ctrl+Sで保存し、ゲームを閉じて`Develop.cmd`を実行します。
4. 開いたF1画面を閉じ、左上の星からメニューを開いて見比べます。

数字を大きくするとパネルが濃く、小さくすると透明になります。`0`と`1`の間を使ってください。`;`と末尾の`f`は残します。元へ戻す場合も`.68f`へ戻して保存・再ビルドします。**C++の設定は保存だけでは反映されません。** 初めてのビルドは[改造ガイド](development-guide.md)で案内しています。

この値は星のメニューと設定のサブメニューに使います。オーラ選択画面の背景は`src/tuning/aura_selector.hpp`、クレジットの背景は`src/tuning/credits.hpp`で調整します。F1や接続先のImGuiウィンドウは、それぞれの描画コードで背景を指定しています。

## 幅・位置・回転の時間を変える

次の値はすべて[src/tuning/shell.hpp](../src/tuning/shell.hpp)にあります。秒数以外の長さは1440×900を基準にした画面座標で、実際のウィンドウに合わせて拡大・縮小します。幅を大きくしすぎると、狭いウィンドウではゲームを覆うので、1項目ずつ試してください。

| 設定 | 標準値 → 試す値 | 画面で変わること |
| --- | --- | --- |
| `PanelOpacity` | `.68f → .50f` | 星のメニューと設定のサブメニューの後ろが見えやすくなる |
| `LeftWidth` | `240.f → 280.f` | 左メニューが右側へ広がる。クリック範囲も一緒に広がる |
| `SettingsWidth` | `300.f → 332.f` | 設定のサブメニューが右側へ広がる |
| `LeftRowHeight` | `62.f → 70.f` | 左メニューの各行が縦に広がり、パネル全体も高くなる |
| `SettingsRowHeight` | `58.f → 66.f` | 設定のサブメニューの行が縦に広がる |
| `MenuPadding` | `16.f → 20.f` | パネルの端と項目の間の余白が広がる |
| `LogoSpinSeconds` | `.65f → 1.f` | 星が1回転するまで1秒かかる。左メニューが開くのも1秒後になる |
| `LeftMargin` | `20.f → 32.f` | 左メニュー全体が右へ12移動する |
| `MenuTop` | `96.f → 112.f` | 左メニュー全体が下へ16移動する |
| `EdgeMargin` | `24.f → 32.f` | 炎が右下から離れる |
| `AuraButtonSize` | `52.f → 60.f` | 炎のボタンとクリック範囲が大きくなる |
| `RollBottomMargin` | `42.f → 58.f` | RollとAutoRollが一緒に上へ16移動する |
| `RollWidth` | `210.f → 230.f` | Rollが横へ広がる。2個のボタン全体は中央に並ぶ |
| `HoverOpacity` | `.12f → .20f` | マウスを乗せた行が少し明るくなる |

星を押したときの回転と、ロケットの周回には**別の時計**があります。`LogoSpinSeconds=.65f`は星の1回転とメニューの待ち時間です。[src/tuning/branding.hpp](../src/tuning/branding.hpp)の`OrbitSeconds=5.f`は、ロケットが白い輪を1周する秒数で、今回も5秒のままです。ロゴ画像の位置・大きさ・ロケット軌道は[ブランド画像のガイド](branding-guide.md)を使ってください。

## 処理を読みたいときの地図

| ファイル | 担当している処理 |
| --- | --- |
| [src/tuning/shell.hpp](../src/tuning/shell.hpp) | 初心者が変更する幅・透明度・秒数 |
| [src/core/shell.hpp](../src/core/shell.hpp) | メニューを開く状態と星の1回転、画面に描く四角とクリック判定の共有 |
| [src/render/ui.cpp](../src/render/ui.cpp) | ロゴ・メニュー・白い炎・Rollをゲームに重ねて描く |
| [src/core/aura_selector.hpp](../src/core/aura_selector.hpp) / [src/tuning/aura_selector.hpp](../src/tuning/aura_selector.hpp) | オーラ選択画面の配置と表示範囲 / 画面の調整値 |
| [src/render/server_settings_ui.cpp](../src/render/server_settings_ui.cpp) | 接続先と名前の入力、URL確認、接続・切断ボタンの表示 |
| [src/render/credits.cpp](../src/render/credits.cpp) / [src/core/credits.hpp](../src/core/credits.hpp) | クレジットの画像・文字を描く / フェードの時刻と共通クリック範囲を計算する |
| [src/render/renderer.cpp](../src/render/renderer.cpp) | 3Dをウィンドウ全体へ描く範囲、メニューのクリック判定 |
| [src/platform/main.cpp](../src/platform/main.cpp) | ボタンから届いた命令、接続・設定保存・終了を実行する |

`core/shell.hpp`で描画とクリック判定が同じ四角を使うため、幅だけ変えてクリック位置が古いままになるのを防ぎます。見た目の変更はまず`tuning/shell.hpp`から始め、メニューを押した後の動作を変えたくなったら`main.cpp`の各Actionを追ってください。
