# 砂漠のオーラ3種類

砂漠ステージの通常ロールだけで取得できます。F1 → オーラの専用ボタンからは、未所持でも表示だけ確認できます。プレビューで所持数やロール履歴は増えません。

| オーラ | Luck 1倍の基礎確率 | 見た目 |
| --- | --- | --- |
| Dune / 砂丘 | 1 in 50 | 砂色のらせんと細かい砂粒 |
| Mirage / 蜃気楼 | 1 in 5,000 | 青緑の結晶と揺れる光の弧 |
| Pharaoh / ファラオ | 1 in 250,000 | 太い金のピラミッド・二重床輪・二段の翼と宝石・二重の太陽 |

## 自分で変えてみる

ソースZIPの `src/tuning/desert.hpp` を開き、まず1つだけ変更して保存し、ゲームを閉じて `Develop.cmd` を実行します。

- `DuneRadius = 1.75f` を `2.2f`：砂のらせんが外側へ広がります。
- `DuneSpeed = .65f` を `.35f`：砂の回転がゆっくりになります。
- `SandColor`：赤・緑・青の順に発光の色を変更します。

Mirage・Pharaohにも個別の調整値と日本語コメントがあります。通常の歩行アニメーションを使い、Illusionaryのような固定ポーズは持ちません。

## Pharaohの線・翼・太陽を調整する

v0.1.15ではピラミッドの線を旧`.10f`から`.30f`、床の外輪を旧`.095f`から`.28f`へ太くしました。翼は片側の幅`2.3f → 3.45f`、長い羽を片側`12 → 16`枚にし、短い羽をその手前へ重ねています。青緑の芯と宝石、二重の太陽を加えました。不透明度を抑え、線を太くすることで金色の形を読みやすくしています。

| 設定 | 標準値 | 変更例と結果 |
| --- | --- | --- |
| `PharaohPyramidLineWidth` | `.30f` | `.38f`でピラミッドの辺が太くなる |
| `PharaohFloorLineWidth` | `.28f` | `.20f`で二重床輪の線が細くなる |
| `PharaohFloorInnerRadius` | `.78f` | `.65f`で内側の輪が小さくなり、二重輪の間が広がる |
| `PharaohWingWidth` | `3.45f` | `4.f`で左右の翼がさらに横へ広がる |
| `PharaohWingHeight` | `1.20f` | `1.5f`で翼の外側が持ち上がる |
| `PharaohFeatherLength` | `1.28f` | `1.6f`で外側の長い羽が下へ伸びる |
| `PharaohWingLineWidth` | `.27f` | `.34f`で長い羽の金色の輪郭が太くなる |
| `PharaohSunRadius` | `.78f` | `.9f`で太陽の円が大きくなる |
| `PharaohSunLineWidth` | `.28f` | `.35f`で太陽の輪と光条の線が太くなる |

F1でPharaohを表示し、最初はプレイヤーの正面から見ます。少し上から見ると二重床輪、横から見ると翼の重なりを確認できます。線の太さを変えたい場合は`GoldColor`を明るくするより、表の`LineWidth`を変えると形を保ちやすくなります。

標準値ではPharaohは最大437枚の発光板を同じバッチで描きます。Duneは144枚、Mirageは142枚で、こちらの見た目は変更していません。`Count / Segments`を増やすと描画量も増えるので、大きさと線幅から試すのがおすすめです。

確率は `data/auras.csv` の分母で指定します。今回の追加分はStardustの残余配分から取り、Common 1/2・Uncommon 1/4と、他の分母指定済みオーラは維持しています。
