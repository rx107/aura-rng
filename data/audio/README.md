# オーラ用BGM

| ファイル | 再生条件 | 配布 |
| --- | --- | --- |
| `Tides_of_the_Outer_Reach.mp3` | Singularity表示中 | ソース・公開ZIPに同梱 |
| `Redline_Shift.mp3` | Pixelation Level 1〜2 | 公開ZIPに同梱。GitHubのソースには含めない |
| `Censored.mp3.mpeg` | Pixelation Level 3 | 公開ZIPに同梱。GitHubのソースには含めない |

Tides of the Outer Reachはプロジェクト作者が提供したBGMで、作者の許可によりソース・配布パッケージとともに共有しています。新2曲も提供者から公開ZIPへの同梱許可を得ています。各楽曲の権利はそれぞれの権利者に帰属します。

ソースからビルドした場合は、リリースZIPの`data/audio`を実行ファイルと同じ場所の`data/audio`へコピーしてください。同名ファイルをDownloadsへ置く方法、F1 → Audio / 音楽で任意の場所の曲を選ぶ方法にも対応しています。設定で指定したパスを優先し、初期設定では同梱ファイル、Downloadsの順に探します。音量は音楽・効果音で共通です。

Pixelation Level 0とEquinoxの通常表示にはBGMを設定していません。発射・衝突の効果音はコードから合成するオリジナルPCMで、音源ファイルを必要としません。

Equinoxカットシーン用の参考動画は配布していません。Downloadsに`EquinoxReworkedCutscene.mp4.mp4`があるときだけ音声をローカル再生し、約10.9秒の演出終了時に停止します。動画がない環境でも映像演出は再生できます。
